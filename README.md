# Lumux Detailing — Premium Car Detailing a Domicilio

Sitio web oficial para **Lumux Detailing**, servicio de car detailing de alta gama a domicilio para Zona Sur.

## 🚀 Características
- **Hero con estética visual impactante**: Cartel luminoso de neón "DETAILING" con iluminación automotriz de estudio.
- **Tipografía moderna y minimalista**: Plus Jakarta Sans e Inter con interlineado ajustado y diseño editorial.
- **Sección de Especialistas**: Equipo con calificaciones y especialidades (Master en pulido, Coating cerámico y PPF).
- **Catálogo de Servicios y Precios**: Lavado por fases, tratamiento cerámico, corrección de laca y protección integral.
- **Galería de Trabajos & Portfolio**: Acabados tipo espejo, antes y después, e interiores.
- **Preguntas Frecuentes (FAQ)**: Respuestas a las consultas más habituales sobre servicios a domicilio.
- **Integración con WhatsApp**: Botón flotante y formulario directo para agendar turnos de manera ágil.
- **Responsive Design**: Optimizado para dispositivos móviles, tablets y pantallas de escritorio.

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 Vanilla (variables, grid, flexbox, animaciones y glassmorphism)
- JavaScript Vanilla (animaciones de scroll, acordeones, filtros de precios y contadores)
